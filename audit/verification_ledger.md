## B. 내부 불일치·정의 결함

| 위치/항목 | 관찰 | 판정 |
|---|---|---|
| 표 2 누적수익률 vs CAGR | JSON의 누적수익률에 11.5년을 적용해 역산하면 CAGR은 7.865%, 8.451%, 9.244%, 14.864%로 표시 CAGR 7.85%, 8.42%, 9.14%, 14.82%와 다름. JSON의 체제별 집계 CAGR도 7.87%, 8.45%, 9.24%, 14.86%로 별도 표시됨 | **내부 불일치** |
| 기간 정의 | 문서는 2015-01-02~2026-08-31, 2,868 거래일, 11년 8개월을 동시에 주장하고 스크립트는 `SAMPLE_YEARS=11.5`를 사용함. 누적값과 CAGR의 정확한 기간/정밀 원자료가 제시되지 않음 | **검증 불가·정의 불명확** |
| Sharpe | 식 (33b)는 `mu_ann-r_f`를 정의하지만 실제 표 값은 `(CAGR-2.0)/sigma`와 일치한다. 제안 모델은 `(14.82-2)/7.63=1.68`; 산술평균 15.11%를 사용하면 1.72 | **정의-계산 불일치** |
| Sortino | `r_f=2.0%` 연율을 일별 로그수익률의 `r_t-r_f`에 직접 넣는 표기라면 단위가 섞인다. 일별 무위험률 변환 또는 연율화 절차가 명시되지 않음 | **검증 불가·단위 결함** |
| 통계적 유의성 | `p<0.001`, 블록 길이 10, B=10,000을 주장하지만 원자료·부트스트랩 결과·실행 코드가 없음. `verify_integrity.py`는 이 검정을 수행하지 않음 | **검증 불가** |
| 실증 항력의 “완벽한 일치” | `mu`, `g`, `sigma`가 코드에 상수로 입력되어 있고 원 수익률이 없어, 이론식과 보정값이 맞는 것만 확인됨 | **내부 정합만 확인** |
| Higham 투영 | 식 (25)의 고유값 바닥값 절단은 정규화된 PSD 보정/정규화와 다르며, `epsilon_floor>0`를 포함한 결과를 그대로 Higham 최근접 상관행렬이라고 부를 수 없음 | **방법론 표현 부분 부정확** |
| 식 (19) 표기 | 쌍별 합의 중괄호가 `\sum_i{\sum_j w_i}w_j`로 배치되어 의도한 `\sum_i\sum_j w_iw_j`와 문법적으로 다름 | **형식 결함** |

## C. 데이터·재현성

- 폴더에는 원시 CSV/Parquet 가격자료, 실제 TSFM 가중치·체크포인트, 오토인코더 학습 코드, CVX/QP 실행 코드, 부트스트랩 결과가 없다.
- `data/backtest_results.json`과 `calculate_empirical_metrics.py`는 원자료에서 통계를 산출하지 않고 자산별·전략별 수치를 상수로 입력한 뒤 파생값을 계산한다.
- 따라서 티커·TR 조정주가·배당 재투자·ADF 통계량·MDD·CVaR·거래비용·회전율·세이프가드 발동일·복구일·TSFM 우월성은 **현실 데이터 기준 재현 불가**이다.
- 2020/2022 위기 표와 “자체 시뮬레이션” 수치는 내부 파일 안에서 독립 원천으로 연결되지 않는다.

## D. 외부 사실·문헌

- 연준의 2020-03-15/16 긴급 100bp 인하와 2020-03-23 국채·MBS 매입 확대/무제한 매입 발표는 연준 공식 문서로 확인되는 역사적 사실이다.
- VIX 2020-03-16 종가 82.69(반올림 82.7)는 FRED/CBOE 계열 기록과 부합한다.
- 국민연금 5차 재정계산의 개혁 전 2041년 수지적자·2055년 소진 전망은 확인되지만, 2025년 개혁 이후 전망이 2048/2065로 변경되었으므로 2026년 현재 문맥에서 2055를 무조건 현재 전망처럼 쓰면 시점 조건이 빠진다.
- 퇴직연금 위험자산 70% 한도는 현행 규정 취지와 부합하나, 최종 판정에는 법령 원문 조항을 직접 인용해야 한다. 검색 결과만으로 조문·적용대상을 확정하지 않는다.
- TimesFM 서지(Das et al., 2024)는 PMLR 공식 기록과 부합한다. 나머지 21편은 목록상 식별 가능하지만 각 DOI/원문 대조를 모두 완료한 것으로 간주하지 않는다.
- 본문 인용 `Merton (1971)`, `Willenbrock (2011)`, `Gell-Mann and Peters (2016)`는 참고문헌 목록에 없다. 이는 인용-참고문헌 완결성 결함이다.
- `PatchTST`를 “foundation model”로 단정하는 것은 원 논문의 사전학습·범용성 범위와 별도로 정의를 명시해야 하므로, 문헌 사실과 연구자의 모델 명명 주장을 구분해야 한다.

## 종합 판정

내부 저장값·문서 문자열·일부 결정론적 공식은 일치한다. 그러나 보고서의 핵심 실증 결론(실제 시장 성과, TSFM/NDE 효과, 부트스트랩 유의성, 위기 방어)은 원천 데이터와 실행 파이프라인 부재로 사실로 확정할 수 없다. 따라서 기존 문서의 “100% 검증”, “완벽히 입증”, “엄밀한 백테스팅” 표현은 **내부 보정값 감사 결과를 넘어선 과도한 결론**이다.
